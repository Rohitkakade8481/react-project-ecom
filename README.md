# 🛍️ E-Commerce Website

A simple and responsive E-Commerce Website built using **React.js**, **Tailwind CSS**, **React Router**, **Axios**, and **Fake Store API (EscuelaJS API)**.

---

# 📌 Project Overview

This project is a simple e-commerce website where users can:

* View all products
* View products by category
* Search products
* View product details
* Add products to cart
* Increase/Decrease product quantity
* Remove products from cart
* View total cart price
* Login 

---

# 🚀 Technologies Used

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6)
* React Router DOM
* Axios
* Local Storage
* EscuelaJS Fake Store API

# ⚙️ Installation

## Step 1

Clone the repository

```bash
git clone https://github.com/your-username/react-project-ecom.git
```

---

## Step 2

Open project

```bash
cd ecommerce-react
```

---

## Step 3

Install Dependencies

```bash
npm install
```

---

## Step 4

Run Project

```bash
npm run dev
```

# 🌐 API Used

EscuelaJS API

Base URL

```text
https://api.escuelajs.co/api/v1
```

Products API

```text
/products
```

Single Product

```text
/products/:id
```

Categories

```text
/ categories
```

Products By Category

```text
/categories/:id/products
```
